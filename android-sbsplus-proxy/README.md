# SBS Plus Proxy for Android

한국 네트워크의 Android 휴대폰에서 SBS Plus(S03)의 짧은 수명 HLS 토큰을 재생 요청 시마다 새로 받아주는 로컬 HTTP 프록시입니다.

## 사용법
1. APK 설치 후 앱 실행.
2. `서버 시작`을 누릅니다.
3. 앱에 표시되는 `http://<휴대폰IP>:8787/sbsplus.m3u8` 중 Chromecast/TiviMate가 접근 가능한 주소를 등록합니다.
4. 필요하면 `휴대폰 부팅 후 자동 시작`을 켭니다.

플레이어는 고정 로컬 주소만 사용하고, 앱이 요청 때마다 SBS S03 API에서 새 mediaurl을 받아 HTTP 302로 연결합니다. 토큰 URL 자체를 저장하지 않습니다.

## 주의
- 휴대폰과 Chromecast/TiviMate가 서로 접근 가능한 같은 로컬/테더링 네트워크에 있어야 합니다.
- 제조사 배터리 절전 정책이 Foreground Service를 종료할 수 있으므로 필요하면 이 앱을 배터리 최적화 대상에서 제외하세요.
- 부팅 자동 시작은 제조사 정책에 따라 제한될 수 있습니다. 앱을 한 번 열고 `서버 시작`을 누르면 정상 실행됩니다.
- SBS의 공식 API/스트림 정책이 바뀌면 resolver 갱신이 필요할 수 있습니다.
